# ليبيا بوينت | Libya Point

**Libya Point** هو دليل خدمات ليبي شامل يجمع في تطبيق واحد: الخدمات الحكومية، المؤسسات الرسمية، المصارف وتطبيقاتها، الطوارئ، الصحة، الطاقة، السفر، الوظائف، التعليم، الأخبار، الاتصالات، التسوق والخدمات اليومية، مع البحث والمفضلة والعمل دون اتصال في البيانات الحرجة.

## ما الجديد في الإصدار 1.2.0

- إعادة بناء بطاقات الدليل لتدعم عدة إجراءات داخل البطاقة بدل رابط واحد فقط.
- إضافة مصدر البطاقة وحالة كونها رسمية وتاريخ آخر تحقق.
- إعادة بناء قسم المصارف وفق دليل مصرف ليبيا المركزي، مع دعم تطبيقات Android والخدمات البنكية المتعددة.
- فصل التطبيقات المصرفية عن دليل التطبيقات العامة لتقليل التكرار.
- توسيع قسم الدولة والمؤسسات الرسمية.
- توسيع الأخبار لتشمل الجهات الحكومية والمصرف المركزي والجهات الخدمية ومصادر إعلامية مستقلة.
- إضافة مركز للطوارئ وأرقام الاتصال والنسخ ومعلومات المصدر، مع إبقاء الأرقام الحرجة داخل التطبيق.
- إضافة خدمات المواطن والجوازات والجمارك والضمان والمياه والحكومة المحلية.
- إضافة الطاقة والنفط والكهرباء، مع روابط وخدمات الاتصال.
- دعم التحقق من الروابط والتكرارات ومعرّفات البطاقات من خلال `tools/check_links.py`.
- دعم المحتوى البعيد `content/content.json` بصيغة schema v2.

## البيانات المباشرة

| البيان | المصدر/الآلية | الملاحظات |
|---|---|---|
| سعر الصرف الرسمي | مصرف ليبيا المركزي | يعرض المصدر والتاريخ عند توفرهما |
| السوق الموازي | مصدر خارجي موضح داخل التطبيق | ليس سعرًا رسميًا |
| الذهب | Gold API | السعر العالمي لا يشمل المصنعية المحلية |
| الطقس | Open-Meteo | حسب المدينة |
| الأخبار | مصادر RSS وبحث موجه للجهات | يتم إبراز المصدر للمستخدم |
| النفط | OilPrice API عند توفير مفتاح الخدمة | المفتاح ليس سرًا حقيقيًا داخل APK، وللتطبيقات العامة يفضّل استخدام وسيط خادمي |

## التحقق من المحتوى والروابط

```bash
python3 tools/check_links.py
```

الفاحص يبحث عن:

- معرّفات مكررة.
- روابط غير صحيحة أو غير آمنة.
- روابط التطبيقات التي لا تستخدم HTTPS.
- عناصر ناقصة المصدر أو البيانات الأساسية.
- ملفات `content.json` غير الصالحة.

ويعمل تلقائيًا عبر GitHub Actions من خلال `.github/workflows/check_links.yml`.

## المحتوى البعيد

التطبيق يقرأ `content/content.json` كل 30 دقيقة، مع الاحتفاظ بآخر نسخة صالحة عند تعذر الاتصال. الصيغة الحالية **schema v2** وتدعم البطاقات متعددة الروابط، المصادر، الأقسام، الفنادق، الأخبار، الإعلانات ورسائل التحديث.

قبل النشر يجب أن يكون مستودع المحتوى متاحًا للقراءة العامة إذا كان التطبيق موزعًا للمستخدمين.

## الأمان ومفاتيح API

أي مفتاح يتم تضمينه في تطبيق الهاتف يمكن استخراجه من APK. لذلك لا تضع مفاتيح سرية عالية الحساسية داخل `--dart-define` إذا كان استخدامها يحتاج حماية حقيقية. استخدم خدمة وسيطة على الخادم عند الحاجة.

## تنظيم المحتوى

الهيكل الحالي يركز على الوصول المباشر:

- **الطوارئ:** الاتصال والنسخ ومصادر الأرقام وخدمات الشرطة والصحة والطوارئ.
- **المصارف والدفع:** المصرف + الموقع + التطبيقات + الخدمات + الهاتف.
- **الدولة والمؤسسات:** البرلمان، المجلس الأعلى للدولة، الحكومة، الوزارات والهيئات.
- **خدمات المواطن:** الجوازات، الجمارك، الضمان، الحكومة المحلية، المرافق.
- **الشكاوى والبلاغات:** منصة رقيب، مركز الاتصال المحلي، الجمارك، الكهرباء والاتصالات.
- **الصحة:** وزارة الصحة، الصيدلة، المركز الوطني لمكافحة الأمراض، والطوارئ.
- **السفر:** المطارات، شركات الطيران، الجمارك والنقل البحري.
- **الطاقة:** الكهرباء، النفط والغاز، المؤسسة الوطنية للنفط، البريقة.
- **الأخبار:** مصادر رسمية ومصادر إعلامية مستقلة مع فصل نوع المصدر.

## قواعد مهمة للمساهمات

1. لا تضف موقعًا أو تطبيقًا على أنه رسمي إلا بعد التحقق من الجهة المالكة والمصدر.
2. لا تستبدل رقم طوارئ قديمًا برقم جديد دون توثيق المصدر وتاريخ التحقق.
3. عند توفر تطبيق رسمي، استخدم رابط المتجر المباشر إذا تم التحقق من اسم المطور والحزمة؛ وإلا استخدم بحث المتجر بدل رابط قد يكون غير صحيح.
4. تجنب إضافة نفس الخدمة كعنصر مستقل أكثر من مرة، إلا عندما تكون الإضافة في سياق مختلف بوضوح.
5. لا تضع مفاتيح API السرية داخل المستودع.
